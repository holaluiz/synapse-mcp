Why Synapse MCP?

🛡️

100% Local-First

All state lives in .synapse/brain.db. Zero cloud dependencies, zero external network sockets, zero telemetry.

🔒

Anti-Collision Locks

File locks prevent race conditions when multiple agents edit the same repository simultaneously.

📜

Shared Architecture Memory

Architectural Decision Records (ADRs) persist across agents so established conventions are never reverted.

❓

Investigation Unknowns

Agents flag unanswered questions or unexpected bugs for peer agents to investigate and resolve.
